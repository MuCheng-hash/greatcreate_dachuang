## Decisions

1. 仅在规则检测到指代或缺少检索主体时调用 LLM 改写；输出只允许结构化检索条件，失败回退原问题。
2. 首轮保留 Dense + Lexical；当候选不足三条或最高 RRF 小于 `0.020` 时，Python 并行生成 HyDE 与 Tavily 白名单结果，并通过第二次内部检索请求交给 Java 完成最终融合。
3. Web 结果必须来自管理员启用的 HTTPS 域名，作为 `WEB` 引用候选，不伪装为知识库 Chunk。
4. 云端 `qwen3-rerank` 对最多 32 条文本和 Web 候选精排；失败时使用已有启发式重排并标记降级。
5. 图谱路由与审核过滤保持 P1 行为；内部二次检索不增加 Agent 工具计数。
