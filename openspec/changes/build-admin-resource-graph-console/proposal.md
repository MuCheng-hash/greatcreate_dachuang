## Why

管理员后台已具备学校、资源和 RAG 运维的基础页面，但驾驶舱指标不完整，资源只能管理本地教育资源，且缺少可审计的图谱实体维护与 Excel 导入。需要在保持既有接口兼容的前提下，让管理员能够建设并发布可追溯的资源和图谱数据。

## What Changes

- 增加驾驶舱汇总，展示资源、学校、教师、学生、问答、方案和索引状态。
- 将资源管理扩展为资源、遗址、纪念馆、人物、事件、故事及白名单关系的统一目录。
- 增加审核、逻辑停用、媒体和来源关联，以及审核发布后的 Neo4j/RAG 投影。
- 增加多工作表 Excel 模板、预检、确认导入和结果报告。
- 强化资源 Excel 导入闭环：支持资源核心字段、表头别名识别、行政区域与坐标校验、数据库去重，以及待审核关系导入。

## Impact

- `business-service` 管理接口、领域服务、MySQL 脚本、Neo4j 投影和静态后台页面。
- 新增 Excel 处理依赖与管理端测试；现有 `/api/admin/resources` 保持可用。
