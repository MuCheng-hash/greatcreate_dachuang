## Why

生成完成后的“实际模型”会占用最终结果区域，记忆中心的删除确认仍使用浏览器原生弹窗，推断出的待确认记忆则混在长回答末尾，三者的视觉和交互均与工作台不一致。需要在不改变模型、记忆生命周期或后端契约的前提下，统一优化这些前端体验。

## What Changes

- 让智能问答和教学方案的“实际模型”仅作为流式生成期间的状态提示；最终结果、失败、停止和历史恢复时不再显示。
- 新增项目内确认弹窗，替代记忆中心单条删除、永久删除和清空列表使用的浏览器原生确认框。
- 为危险操作提供明确的影响说明、取消与确认操作、键盘可访问性、焦点管理和请求中防重复提交。
- 将智能问答的待确认记忆从回答内部移至输入框上方的常驻操作区，集中展示当前会话尚未处理的候选，并保留原有确认、忽略、失败保留和焦点恢复行为。
- 将候选记忆确认或忽略后的成功提示限制为 5 秒自动消失，避免输入区持续保留已完成的操作信息；失败提示仍保留，直至用户继续操作或离开会话。

## Capabilities

### New Capabilities

- `generation-status-presentation`: 在生成过程中展示临时模型状态，并在最终结果阶段隐藏该状态。
- `memory-destructive-confirmation`: 以工作台内的无障碍确认弹窗保护记忆中心的破坏性操作，并让待确认记忆在输入区获得明确、可直接操作的呈现。

### Modified Capabilities

- 无。

## Impact

- 影响 Vue 前端的智能问答、教学方案和记忆中心组件，以及相应 Vitest 回归测试。
- 新增一个不依赖第三方库的前端确认弹窗组件；不改变 Spring、FastAPI、SQLite、公开 API 或 SSE 事件结构。
